\# Reflection - Assignment 1 (Start / Stop / Continue)



\## Start

\- Writing a test that will fail before writing any code. Seeing how the test turns from red to green helped build my confidence in the code, and I began to think of tests as a form of specification. I would love to apply Red Green Refactor on all of my projects.

\- Performing a quick mutation to show how a test fails.



\## Stop

\- Stop working fast to meet the deadline.  Because of that some test cases had spelling mistakes in file names, which costed me a lot of errors and they were hard to fix after committing the changes. 



\## Continue

\- Using Arrange-Act-Assert with descriptive test names; failure messages told me exactly what broke.

\- Giving each class a single responsibility (for example, moving tip math into TipCalculator so it is not duplicated).



\## What I learned

Penny reconciliation showed me that money needs deliberate rounding rules: Banker's rounding, ceiling and floor behave

differently, and rounded parts may not add up to the rounded total.
